# Changelog

## 0.1.0 — 2026-10-08

Primera versión pública.

- Cuatro skills por rol: `aura-workflow`, `aura-lead` (con guías de spec, reparto y Gate),
  `aura-builder` y `aura-git-isolation`.
- Plantillas: perfil del proyecto (`.aura/project.md`), skill de contexto y skill de design system.
- `install.sh` para Claude Code, Codex y OpenCode (carpetas medidas el 2026-10-08 en Linux).
- Funciona con Aura Runtime 0.1.0-beta.6 o posterior (buzón `aura-mailbox` con seis herramientas;
  beta.6 es la que le da un nombre propio a cada terminal de Codex).
  Sin Aura también funciona, sin buzón.
